# 🔎 Build Forensic Workstation

## Overview

I learned how to build and prepare a dedicated forensic workstation
for performing digital forensic investigations in a controlled
environment.

## What I Learned

- Purpose of a forensic workstation
- Preparing a suitable forensic analysis environment
- Installing and configuring forensic tools
- Organizing forensic investigation resources
- Maintaining a controlled analysis environment
- Importance of protecting evidence integrity

## 🛠️ Tools Used / Studied

- Oracle VirtualBox
- FTK Imager
- KAPE
- Eric Zimmerman's forensic tools
- Windows Event Viewer
- PowerShell
- Command Prompt

## Practical Learning

I worked on preparing a dedicated environment that can be used to
examine forensic evidence and analyze artifacts collected from
Windows systems.

## Key Takeaway

A properly prepared forensic workstation provides a controlled
environment for analyzing evidence while reducing the possibility
of accidentally modifying the evidence being investigated.
