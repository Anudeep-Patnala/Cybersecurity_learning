# 🛡️ Cybersecurity Lab Setup

## 📌 Overview

I have built a **virtualized cybersecurity lab** using **VirtualBox** to practice cybersecurity concepts in a controlled environment.

The lab contains multiple virtual machines for:

- 🔐 Security testing
- 🪟 Windows administration
- 🌐 Networking
- 🔎 Digital forensics
- 🦠 Malware analysis

---

## 💻 Virtual Machines

### 1. 🧱 pfSense

**VM Name:** `2026_pfsense`

Used as the **firewall and router** within the lab environment.

**Areas of Learning:**

- Network configuration
- Firewall rules
- Network segmentation
- Traffic control

---

### 2. 🪟 Windows 11

**VM Name:** `2026_win11`

Windows 11 environment used for learning Windows administration and security concepts.

**Areas of Learning:**

- Windows security
- System administration
- Windows configuration
- Security testing

---

### 3. 🐉 Kali Linux

**VM Name:** `kali-linux-2026.2-virtualbox-amd64`

Kali Linux environment used for learning cybersecurity tools and security-testing techniques.

**Areas of Learning:**

- Network security
- Vulnerability assessment
- Security testing
- Reconnaissance
- Cybersecurity tools

---

### 4. 🏢 Windows Server / Domain Controller

**VM Name:** `ECORP-DC`

Used for learning **Windows Server and Active Directory** concepts.

**Areas of Learning:**

- Active Directory
- Domain environments
- User and group management
- Authentication
- Windows administration

---

### 5. 🔎 Windows Forensics

**VM Name:** `Win11_forensics`

Dedicated Windows environment for practicing **digital and Windows forensics**.

**Areas of Learning:**

- Windows Registry
- NTFS
- Event Logs
- Forensic artifacts
- System investigation
- Evidence analysis

---

### 6. 🎯 Victim / Test Machine

**VM Name:** `Victim (clean)`

A clean Windows environment maintained for controlled security experiments and testing.

Snapshots are used to maintain a **known clean state** and restore the machine after experiments when necessary.

---

## 🌐 Lab Architecture

The virtual machines are configured within a controlled virtualized environment to allow communication and security testing between systems.

The lab can be used to study:

- Network communication
- Firewall configuration
- Windows security
- Linux security
- Active Directory
- Digital forensics
- Malware analysis
- Security testing
